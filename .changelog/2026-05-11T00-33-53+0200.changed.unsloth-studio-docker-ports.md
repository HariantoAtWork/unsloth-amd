## Unsloth Studio on `docker compose up`

- Default container command now starts **Unsloth Studio** with `--host 0.0.0.0` so the UI is reachable through published ports.
- **Dockerfile** documents port **8888** via `EXPOSE` and sets `UNSLOTH_STUDIO_HOST` / `UNSLOTH_STUDIO_PORT` defaults.
- **Compose** maps `${UNSLOTH_STUDIO_PORT:-8888}` on both sides so host port overrides stay aligned with the process inside the container.
