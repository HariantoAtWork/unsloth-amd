## ROCm visible to `install.sh` inside the container

- Prepend **`/opt/rocm/bin`** to `PATH` in the image and entrypoint so `rocminfo` / **`amd-smi`** resolve (Unsloth’s installer uses `command -v rocminfo`; without this it wrongly falls back to CPU PyTorch).
- Install **`amd-smi-lib`** so `amd-smi` is available for ROCm wheel-index detection when needed.
- Replace Compose **`devices: /dev/dri`** with **bind mounts** for `/dev/dri` and `/dev/kfd` so all DRM render nodes reach the container; add **`group_add: [video, render]`** for typical `/dev/dri` ACLs.
