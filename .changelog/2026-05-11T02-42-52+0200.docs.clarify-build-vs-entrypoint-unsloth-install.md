## Document when Unsloth installs (runtime, not `docker build`)

- README: **`docker build` does not run `install.sh`**; first **`docker compose up`** runs the entrypoint installer.
- Dockerfile: short comment at top states the same.
- `docker-entrypoint.sh`: restore **`</dev/null`** on the installer `sh` invocation (non-interactive stdin).
