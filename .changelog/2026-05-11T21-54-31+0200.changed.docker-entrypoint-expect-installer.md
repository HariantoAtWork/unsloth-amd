## Run Unsloth `install.sh` under `expect`

- **`docker-entrypoint.sh`**: `curl` installer to a temp file, **`expect`** spawns **`sh`** with it, matches **`Start Unsloth Studio now?`**, sends **`n`**, propagates child exit status, restores marker behaviour.
- **`Dockerfile`**: install **`expect`** in the base apt layer.
- **`README`**: describe expect vs `/dev/tty` and point at optional **`patch.sh`**.
